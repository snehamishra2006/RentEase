# 🏠 RentEase

RentEase is a full-stack **MERN rental property platform** designed for the Indian market. It connects tenants, property owners, and admins to manage property listings, applications, rentals, payments, and maintenance in one place.

## 🌐 Live Demo

🚀 [RentEase — Property Ledger Platform](https://rentease-1-iuwn.onrender.com/properties)

## ✨ Features

### 👤 Tenant
- Search and filter rental properties
- View detailed property information
- Save favorite properties
- Apply for rental properties
- Track rental applications
- View active rental and payment details
- Raise maintenance requests
- AI-powered property search

### 🏠 Owner
- Add and manage property listings
- Upload property images
- Review tenant applications
- Approve or reject applications
- Track available and rented properties
- Monitor rent collection
- Manage maintenance requests

### 🛡️ Admin
- Admin dashboard
- Verify or reject property listings
- Manage users
- Monitor rentals and platform activity
